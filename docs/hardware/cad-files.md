## Coming Soon - 3D Printable Designs

The OpenReef CAD files are currently in development. When complete, they will include:

### Enclosure
- **Main Enclosure Box** (350 × 250 × 300mm)
  - Mounting points for PyBadge
  - Motor controller mounting panel
  - Valve mounting locations
  - Cable management channels
  - Access panels for maintenance

### Mounting Hardware
- **Pump Mount Brackets** - L-brackets for peristaltic pumps
- **Valve Mounting Plate** - Holds 3× Adafruit solenoid valves
- **Sensor Mount** - Cuvette holder with AS7341 positioning
- **Motor Controller Bracket** - Side-panel mount

### Bottle Caps & Fittings
- **3-Port Bottle Caps** - For reagent bottles
  - Inlet tube port
  - Outlet tube port
  - Air vent port
  - Compatible with API test kit bottles

### Cuvette Holder
- **Cuvette Mount**
  - 1 cm path length cuvette
  - Tube access for bubble mixing
  - AS7341 sensor alignment
  - LED light source positioning

## File Formats

When released, CAD files will be available in multiple formats:

- **FreeCAD** (.FCStd) - Parametric, fully editable
- **STEP** (.step) - Universal CAD format
- **STL** (.stl) - Ready for 3D printing
- **OpenSCAD** (.scad) - Parametric text-based models

## Design Software

The designs are being created using:
- **FreeCAD** (open-source, free)
- **OpenSCAD** (parametric scripting)

Some designs build upon the [IoRodeo Open Colorimeter](https://www.iorodeo.com/collections/colorimeter) designs (CC BY 4.0 license).
