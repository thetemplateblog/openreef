# Legacy — OpenReef v1 (2025)

The original Raspberry Pi colorimeter (Flask web app, TSL2591, Motor HAT, MCP23017 solenoids, Red Sea Pro powder kits), preserved unchanged when the project was rebuilt as the v2 analyzer in November 2026.

- `open_colorimeter_pi/` — the Flask firmware and install scripts
- `hardware/` — v1 CAD (OpenSCAD, OBJ, FreeCAD/Fusion guides) and the OpenColorimeter V1 STEP
- `docs/` — v1 assay protocols, calibration guide, Pi setup and hardware guide (Minimal Mistakes front matter)
- `tools/` — calibration analysis script

Nothing here is built by the website (`legacy/` is excluded in `_config.yml`). See https://openreef.dev/docs/project/legacy/.
